## Exploratory Data Analysis (EDA)
EDA helps us understand the dataset before performing further
analysis.

The analysis includes:
- Understanding dataset dimensions and data types.
- Checking missing values and duplicate records.
- Calculating descriptive statistics.
- Identifying patterns and trends.
- Creating charts and visualizations.
- Summarizing important findings.

## SQL Analysis
SQL queries are used to retrieve, filter, summarize, and analyze
data from a database.

The analysis may include:
- SELECT statements to retrieve data.
- WHERE conditions to filter records.
- GROUP BY to summarize data.
- ORDER BY to sort results.
- Aggregate functions such as COUNT, SUM, AVG, MIN, and MAX.
- Other queries relevant to the dataset.
